# Покерный штурман

Помощник для безлимитного холдема на фишки и в тренажёрах. Даёт совет до флопа по солверным таблицам, считает шанс после флопа и умеет сам разбирать снимок стола.

Приложение рассчитано на игру на фишки и тренировки. Покер-румы запрещают подсказки в игре на деньги.
